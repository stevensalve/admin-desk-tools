Admin Desk Tools

Ten everyday operations and admin tools - visitors, stock, rosters, purchase orders, contracts, rooms and more - that run entirely in your browser. Your data is never uploaded, nothing needs installing, and everything keeps working with no internet.

Using it without internet

  1. Download this project as a ZIP (on GitHub: green Code button, then Download ZIP) and unzip it.
  2. Open index.html in the unzipped folder with Chrome, Edge, Firefox or Safari.
  3. Pick a tool. That's it - you can now disconnect from the internet. You can also copy a single tool's folder and use it on its own.
